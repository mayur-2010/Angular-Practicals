## Practicals Included

### Practical 1 – Student Portfolio

Create an Angular application to display a student portfolio.

**Features:**

* Student name and professional title
* About Me section
* Skills section
* Projects section
* Contact information
* Project links
* Angular `*ngFor` directive
* HTML and CSS styling

## Technologies Used

* Angular
* TypeScript
* HTML
* CSS

## How to Run the Project

```bash
npm install
ng serve
```

Then open:

```text
http://localhost:4200/
```
